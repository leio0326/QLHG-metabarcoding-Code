This is a brief description of the main code used in the QLHG metabarcoding project
01.Usearch_pipeline: This folder contains the analysis process from raw metabarcode sequencing data to OTU reads.
02.Feeding_module: This folder contains the main analysis code from Fig4, including module division and bipartite network diagram of insect and feeding-plant.
03.03.JSDM_model: This folder contains the main analysis code from Fig6, including training the JSDM model and disassembling the ternary graph.
04-1.Prediction_model_precondition: This folder contains preparations for predicting insects using plant models based on cumulative curves and predicting plants using insect insect models. The purpose is to confirm how many sample points to select to ensure a standard deviation of<5% of the mean
04-2.Predict_model: This folder contains running code for predicting insects using plant models based on cumulative curves and predicting plants using insect insect models
